Complete this after finishing all three exercises and the capstone project,
and after your module-end review ("Check my module"). Don't start Module 01

review are done.

## Self-assessment

Answer these honestly, in your own words (writing them down, e.g. in your
`course-companion` repo's notes, is more valuable than answering silently
in your head):

- [ ] I can explain the difference between Git and GitHub without hesitating.
- [ ] I can explain what `PATH` is and diagnose a `command not found` error without panicking.
- [ ] I can navigate anywhere on my filesystem, create/move/copy/delete files and folders, and use at least one pipe — all via the shell, no File Explorer.
- [ ] I can create a Git repo, make several well-separated commits with good messages, and explain why staging is a separate step from committing.
- [ ] I correctly set up a `.gitignore` *before* the file it needed to ignore was ever staged.
- [ ] I have personally resolved a real merge conflict by hand — I can explain what the three conflict markers mean without looking them up.
- [ ] I have pushed a branch, opened a real Pull Request on GitHub, and merged it — and I understand why my local `main` didn't update until I ran `git pull`.
- [ ] Given an unfamiliar error message, I can apply the read-bottom-up, find-my-own-code, then-search method from Lesson 02 instead of guessing randomly.
- [ ] All three exercises were reviewed and scored 7/10 or higher (or revised until they were).
- [ ] The capstone (`course-companion` repo) is complete and pushed to GitHub.
