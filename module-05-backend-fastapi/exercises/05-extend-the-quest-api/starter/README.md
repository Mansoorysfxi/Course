# Exercise 05 — starter

A complete, working, in-memory Quest API -- read it in full before changing
anything. Add the two new endpoints described in `INSTRUCTIONS.md`.

```bash
python -m venv .venv
source .venv/Scripts/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Then visit `http://127.0.0.1:8000/docs`.
